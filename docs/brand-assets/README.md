- **Background**: `#121212` (deep black)
- **Primary accent**: `#FFD700` (gold)
- **Interactive accent**: `#8FBC8F` / `#7CA982` (sage green)
- **Shadow style**: 3D neumorphic (raised + inset shadow layers)
- **Brand slogan**: බැදුම නගරේ රහට * ගානට
- **Typography**: bold black display fonts with gold color and drop shadows
